Engine Features

Built for Modern Web Recon

Comprehensive endpoint discovery with maximum signal and zero noise

🛡️

Zero False-Positive Engine

Dedicated heuristic filters drop XML/SVG namespaces (w3.org), closing HTML tag artifacts, regex flags, template literal syntax, and library internals automatically.

⚡

Deep AST & Regex Mining

Hooks into inline scripts, external JS bundles, Fetch API invocations, Axios handlers, jQuery AJAX calls, and modern async imports to surface hidden routes.

🕷️

Recursive Crawling

Autonomous multi-depth crawler with configurable recursion, internal link discovery, form action analysis, and dynamic SPA route detection.

🕵️

Stealth & WAF Evasion

Configurable human-like delays (2-10s), realistic scroll kinematics, mouse jitter simulation, and randomized User-Agent headers prevent rate limits.

🏷️

Intelligent Route Tagging

Automatic classification into high-priority attack surfaces: Admin Panels, Authentication Handlers, GraphQL Gateways, Payment Webhooks, and API v1-v5 endpoints.

🔒

100% Client-Side & Private

No backend telemetry, no remote analytics, and zero cloud dependencies. Your discovered endpoints and target domain lists never leave your local browser.

Quick Start

Install in 30 Seconds

Load directly into Chrome, Brave, Edge, or any Chromium browser

01

Download or Clone

Clone the repository or download the latest release ZIP from GitHub:

git clone ...

02

Enable Developer Mode

Navigate to chrome://extensions in your Chromium browser and toggle the Developer mode switch in the top right corner.

03

Load Unpacked

Click Load unpacked and select the extension directory. The Endpoint Hunter radar icon will instantly appear in your toolbar!
