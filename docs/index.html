Enterprise Recon Suite

Engineered for Top 1% Precision

Everything an ethical hacker, bug bounty hunter, or security auditor needs inside Chromium

🧪

In-Browser Mini-Repeater

Interactive request dispatcher supporting GET, POST, PUT, DELETE with custom headers, JSON payloads, live latency timers, status code triage, and one-click copy.

🌸

GraphQL Schema Introspection

Discovers schema definitions via standard IntrospectionQuery, categorizes all Queries and Mutations, and generates 1-click test templates for the Repeater.

🗺️

Source-Map (.map) Unpacker

Reconstructs original TypeScript/JS source file trees from webpack and vite `.map` files, unearthing internal routes and API gateways stripped by bundlers.

🔑

TruffleHog Secrets Harvester

High-entropy regex scans client-side assets for leaked AWS credentials, Google API keys, GitHub PATs, Stripe tokens, Slack/Discord webhooks, OpenAI keys, and JWTs.

🕷️

Micro-Fuzzer & Route Dictionary

Rapid non-destructive dictionary probing for Swagger/OpenAPI docs, Spring Boot Actuators, Admin consoles, `.env` files, and `.git/HEAD` leaks with stealth delays.

🛠️

Chrome DevTools (F12) & Side Panel

Inspect applications side-by-side using the persistent Chrome Side Panel or directly inside Developer Tools (F12) right alongside Console and Network.

🛑

Zero Auto-Scan Invariant

Never spies on your background browsing. Scanning and sniffing strictly run when you explicitly click Start, with an immediate kill switch on Stop.

📦

Multi-Format Exporters

Export directly to Postman Collection v2.1, OpenAPI 3.0 specification, clean CLI TXT lists for ffuf and nuclei, structured JSON, or printable triage PDF.

🛡️

100% Offline & Private

Zero external telemetry, zero tracking pixels, and zero remote servers. Everything executes inside your local browser context.

Quick Start

Install in 30 Seconds

Load directly into Chrome, Brave, Edge, or any Chromium browser

01

Download or Clone

Download the release ZIP directly or clone from GitHub:

git clone ...

02

Enable Developer Mode

Navigate to chrome://extensions and toggle the Developer mode switch in the top right corner.

03

Load Unpacked

Click Load unpacked and select the directory. The radar icon will appear in your toolbar and Developer Tools (F12)!
