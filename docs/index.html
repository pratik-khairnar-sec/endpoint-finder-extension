Enterprise Recon Suite

Engineered for Top 1% Precision

Everything an ethical hacker, bug bounty hunter, or security auditor needs inside Chromium

🎖️

Zero-Day Recon Orchestrator

Automated multi-layer mission coordinator executing non-blocking posture checks across CORS, headers, environment files, CRLF, and CSP bypasses with consolidated pass/fail timelines.

📊

CVSS v3.1 Security Scorecard

Real-time vulnerability impact calculation computing exact CVSS v3.1 vector strings and numeric scores (0.0 to 10.0) with an attack surface posture grade gauge (A+ to F).

🛡️

Enterprise MITRE ATT&CK Matrix

Automatically correlates discovered routes, credentials, and network behaviors to official MITRE techniques (T1592, T1595, T1552, T1190, T1530) across Reconnaissance and Access tactics.

🌐

Interactive Topology Graph

Real-time HTML5 Canvas network graph rendering target origin, major cluster hubs (/api, /auth, /admin, /static), and leaf status nodes with live interactive redrawing.

📐

API Schema Boundary Fuzzer

Generates typed boundary test vectors for integer, string, boolean, array, and object parameters (32/64-bit int limits, IEEE-754 precision limits, null bytes, unicode normalization).

✈️

CORS Preflight Simulator

Simulates safe OPTIONS requests with custom origins and headers, evaluating Access-Control-Allow-Origin, Allow-Credentials, and flagging wildcard CSRF risks.

🎲

Shannon Entropy Calculation Lab

Computes Shannon entropy (0.0 to 8.0) on responses and tokens to distinguish high-randomness cryptographic secrets from plain text and static HTML templates.

🏗️

Tech Stack Fingerprinter

Multi-layer signature detection identifying backend engines (Express, Django, Rails, Spring, PHP) and modern frontend frameworks (Next.js, Nuxt, React, Angular).

📦

Burp Suite XML & Postman Env

Native exports for Burp Suite Target Site Map XML (burp_sitemap.xml) and Postman Environment JSON (postman_environment.json) with auto-populated baseUrl and bearer tokens.

📋

Compliance Exporter (OWASP / SOC2 / ISO)

Generates compliance_report.json mapping findings directly to OWASP Top 10 (2021/2025), SOC 2 Type II Common Criteria, and ISO/IEC 27001:2022 controls.

💻

Hunter Ultimate CLI Pipeline Bridge

Generates recon_pipeline.sh orchestrating ffuf, httpx, and nuclei with discovered parameters, wordlists, and status codes for terminal automation.

🎯

Polyglot Injection Probers

Targeted probers for SSTI ({{7*7}}), SQLi syntax error detection, XXE canary entities, client prototype pollution, and CRLF response splitting.

🧪

In-Browser Mini-Repeater

Burp-style HTTP dispatcher supporting GET, POST, PUT, DELETE, PATCH with custom headers, multi-role session switching, latency measurement, and JSON formatter.

🌸

GraphQL Introspection & Mock Ops

Introspects GraphQL schemas, maps Queries and Mutations, and automatically synthesizes executable query operations with mock variables.

🗺️

Source-Map (.map) Unpacker

Reconstructs original TypeScript/JS source file trees from webpack and vite .map files, unearthing internal routes stripped from production bundles.

🔑

TruffleHog Secrets Harvester

High-entropy regex scans client-side assets for leaked AWS credentials, Google API keys, GitHub PATs, Stripe tokens, Slack/Discord webhooks, and JWTs.

🔌

WebSocket & SSE Interceptor

Real-time frame capture of window.WebSocket (send/message) and window.EventSource streams with direction markers and payload mutator.

🛑

Zero Auto-Scan & 100% Offline

Strictly enforces a zero auto-start policy. Never scans without your explicit button click, zero telemetry, and zero remote communication.

Quick Start

Install in 30 Seconds

Load directly into Chrome, Brave, Edge, or any Chromium browser

01

Download or Clone

Download the release ZIP directly or clone from GitHub:

git clone ...

02

Enable Developer Mode

Navigate to chrome://extensions and toggle the Developer mode switch in the top right corner.

03

Load Unpacked

Click Load unpacked and select the directory. The radar icon will appear in your toolbar and Developer Tools (F12)!
